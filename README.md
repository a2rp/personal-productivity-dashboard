# Personal Productivity Dashboard

Personal Productivity Dashboard brings the daily open tasks, focus time, and recent completions into one practical overview.

## Interface

The dashboard combines task and completion totals, a task list with priorities, a 25-minute focus timer, a seven-day completion chart, and a personal reminder.

## Features and use

Add a task with a priority and check it off when complete. The weekly chart updates from completion dates. Start or pause a 25-minute focus block and reset it when needed. Edit the reminder at the bottom of the page.

## Data and limits

Tasks, completion dates, focus-session count, and the reminder are saved in localStorage. The live timer itself resets when the page reloads. Data stays in this browser and is not synced.

## Run locally

Use Node.js and npm, then run these commands from the project folder:

```sh
npm install
npm run dev
```

The app is built with React and Vite. Check the source and production build with:

```sh
npm run lint
npm run build
```

## Deployment

The public app is published with GitHub Pages at [https://a2rp.github.io/personal-productivity-dashboard/](https://a2rp.github.io/personal-productivity-dashboard/). To build and publish the current version, run:

```sh
npm run deploy
```
